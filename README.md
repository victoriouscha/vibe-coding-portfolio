# VS Code와 Cline을 활용한 대학생 포트폴리오 제작

> **실습 과정:** 기획 → 기본 웹사이트 생성 → 콘텐츠 추가 → 디자인 개선 → 기능 수정 → GitHub 배포  
> **실행 환경:** VS Code, Cline, HTML, CSS, JavaScript, Git, GitHub Pages  
> **대상:** 대학생 및 취업 준비생

## 1. 실습 개요

바이브 코딩(Vibe Coding)을 활용하여 자신의 전공, 역량, 프로젝트 및 활동 경험을 소개하는 개인 포트폴리오 웹사이트를 제작하고 GitHub Pages를 통해 공개합니다.

### 실습 목표

- AI 코딩 에이전트를 활용하여 웹사이트를 기획하고 구현한다.
- 프롬프트를 활용하여 콘텐츠, 디자인 및 기능을 개선한다.
- Git과 GitHub를 활용하여 소스코드를 관리한다.
- GitHub Pages를 활용하여 공개 URL을 생성한다.

### 실습 환경

| 구분             | 내용                  |
|------------------|-----------------------|
| 개발 환경        | Visual Studio Code    |
| AI 코딩 에이전트 | Cline                 |
| 개발 언어        | HTML, CSS, JavaScript |
| 개발 방식        | Vibe Coding           |
| 버전 관리        | Git                   |
| 저장소           | GitHub                |
| 배포             | GitHub Pages          |

## 2. 전체 실습 과정

| 단계 | 실습 주제          | 주요 결과물            |
|------|--------------------|------------------------|
| 01   | 포트폴리오 기획    | PLAN.md                |
| 02   | 기본 웹사이트 생성 | HTML, CSS, JavaScript  |
| 03   | 콘텐츠 추가        | 개인 포트폴리오 콘텐츠 |
| 04   | 디자인 개선        | 디자인 변경 웹사이트   |
| 05   | 기능 수정 및 검증  | 기능 점검 및 오류 수정 |
| 06   | GitHub 배포        | 공개 홈페이지 URL      |

## STEP 01. 포트폴리오 기획

### 1. 개발 환경 준비

1.  VS Code와 Cline을 설치하고 AI 모델 및 API 연결을 설정한다.
2.  Windows 파일 탐색기에서 `student-portfolio` 폴더를 생성한다.
3.  VS Code에서 **File → Open Folder**를 선택하여 폴더를 연다.
4.  Cline을 실행한다.

### 2. 포트폴리오 메뉴 구성

| 메뉴       | 주요 내용                         |
|------------|-----------------------------------|
| Home       | 메인 화면 및 핵심 메시지          |
| About      | 자기소개 및 학력                  |
| Skills     | 보유 기술 및 핵심 역량            |
| Projects   | 프로젝트 수행 경험                |
| Experience | 대외활동, 자격증, 수상 경력       |
| Contact    | 공개 가능한 이메일 및 GitHub 링크 |

### 3. 실습 프롬프트 ① — 포트폴리오 기획

``` text
당신은 전문 웹 기획자이자 UI/UX 디자이너입니다.
대학생의 취업을 위한 개인 포트폴리오 웹사이트를 제작하려고 합니다.

[제작 목적]
- 취업 및 인턴십 지원
- 전공 지식과 핵심 역량 소개
- 프로젝트 및 활동 경험 소개

[주요 메뉴]
- Home: 메인 화면
- About: 자기소개 및 학력
- Skills: 보유 기술 및 핵심 역량
- Projects: 프로젝트 수행 경험
- Experience: 대외활동, 자격증 및 수상 경력
- Contact: 이메일 및 GitHub 링크

[디자인 요구사항]
- 밝고 전문적인 디자인
- 직관적인 메뉴 구성
- PC와 스마트폰에서 사용 가능한 반응형 디자인

[개발 환경]
- HTML, CSS, JavaScript
- 별도의 백엔드 서버 및 데이터베이스 사용 금지
- GitHub Pages를 통한 배포

웹사이트의 전체 구조, 메뉴별 콘텐츠, 화면 구성 및 개발 계획을 작성해 주세요.
기획 결과는 PLAN.md 파일로 저장해 주세요.
아직 웹사이트 소스코드는 작성하지 마세요.
```

Plan Mode에서 실행한 후, 프로젝트 폴더에 `PLAN.md`가 생성되었는지 확인한다.

### 2. 실습 프롬프트 ② — 기본 웹사이트 생성

``` text
당신은 전문 프론트엔드 개발자입니다.
현재 프로젝트 폴더에 있는 PLAN.md 파일을 읽고, 해당 기획안을 기반으로 대학생 취업용 포트폴리오 웹사이트의 기본 구조를 제작해 주세요.

[파일 구성]
- index.html
- style.css
- script.js

[제작 요구사항]
1. 상단에 내비게이션 메뉴를 배치해 주세요.
2. Home, About, Skills, Projects, Experience, Contact 영역을 생성해 주세요.
3. 각 영역에는 간단한 예시 콘텐츠를 넣어 주세요.
4. 메뉴를 클릭하면 해당 영역으로 이동하도록 구현해 주세요.
5. HTML, CSS, JavaScript는 각각 별도의 파일로 작성해 주세요.
6. 외부 프레임워크는 사용하지 마세요.
7. 디자인은 기본적인 형태로만 구성해 주세요.
8. 기존 PLAN.md 파일은 수정하지 마세요.

현재 프로젝트 폴더에 필요한 파일을 직접 생성해 주세요.
```
act Mode에서 실행한다.

### 3. 프로젝트 파일 구조

``` text
student-portfolio/
├── PLAN.md
├── index.html
├── style.css
└── script.js
```

실제 강사 예제에서는 CSS, JavaScript 및 이미지 파일을 별도 폴더로 관리하였다.

``` text
seunghui-website/
├── css/
│   └── style.css
├── images/
├── js/
├── README.md
└── index.html
```

### 4. 웹사이트 실행

**방법 ①** 파일 탐색기에서 `index.html`을 더블클릭한다.

**방법 ②** Python이 설치된 경우 프로젝트 폴더의 VS Code 터미널에서 실행한다.

``` bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`에 접속한다. 서버 종료는 `Ctrl + C`이다.

## STEP 04. 디자인 개선

### 1. 디자인 스타일 이해

| 스타일             | 특징                                 |
|--------------------|--------------------------------------|
| 3D Clay Style      | 점토 질감과 부드러운 입체감          |
| Soft Pastel Colors | 화사하고 부드러운 파스텔 색상        |
| Warm Minimalism    | 따뜻하고 간결한 디자인               |
| Organic Design     | 자연스러운 곡선과 유기적 형태        |
| Bento Grid         | 모듈형 카드 레이아웃                 |
| Neumorphism        | 부드러운 그림자를 활용한 입체 디자인 |

### 2. 기존 디자인 백업

CSS만 변경한다면 CSS 파일을 백업할 수 있지만, HTML 구조나 이미지까지 변경될 수 있으므로 프로젝트 폴더 전체를 복사하는 것이 안전하다.

``` text
C:\yu-ai\
├── seunghui-website/
└── seunghui-website-backup/
```

Windows 파일 탐색기에서 폴더를 복사하거나 PowerShell에서 다음 명령을 실행한다. 백업 폴더가 아직 존재하지 않을 때 실행한다.

``` powershell
Copy-Item "C:\yu-ai\seunghui-website" "C:\yu-ai\seunghui-website-backup" -Recurse
```

학생은 자신의 실제 폴더 경로로 변경한다. Git을 사용 중이라면 변경 전 커밋으로 이력을 보존할 수도 있다.

### 3. 디자인 레퍼런스 활용

원하는 홈페이지 디자인 이미지를 준비하고 Cline에 첨부한다. 이미지 입력을 지원하는 모델을 사용한다. 참고 이미지의 콘텐츠를 복제하지 않고 색상, 분위기, 레이아웃 및 입체감을 참고한다.

**실습 콘셉트: 3D Clay + Warm Soft Pastel Colors**

| 색상   | HEX       |
|--------|-----------|
| 크림   | `#FFF5E9` |
| 피치   | `#FFDEC1` |
| 살구   | `#FFB58C` |
| 오렌지 | `#EF813D` |
| 브라운 | `#503528` |

### 4. 실습 프롬프트 ④ — 디자인 변경

``` text
당신은 전문 웹 UI/UX 디자이너이자 프론트엔드 개발자입니다.
현재 완성된 개인 홈페이지의 디자인을 첨부한 레퍼런스 이미지의 스타일로 변경해 주세요.
첨부 이미지의 콘텐츠를 복제하는 것이 아니라 색상, 분위기, 레이아웃, 입체감, 디자인 스타일을 참고해 주세요.

[디자인 콘셉트]
- 3D Clay Style
- Warm Soft Pastel Colors
- Claymorphism
- Organic Shapes
- Soft Lighting
- Warm and Friendly Design
- Premium Personal Branding Website

[디자인 요구사항]
1. 첨부 이미지와 같이 화사하고 따뜻한 분위기로 디자인해 주세요.
2. 크림색, 피치색, 살구색, 파스텔 오렌지색을 중심으로 색상을 구성해 주세요.
3. 기존의 진한 파란색, 네이비, 차가운 색상의 배경을 제거해 주세요.
4. 메인 화면은 왼쪽에 핵심 메시지와 버튼, 오른쪽에 전공과 전문 분야를 상징하는 3D Clay 스타일의 시각 요소가 배치되도록 구성해 주세요.
5. 배경에는 부드러운 곡선과 유기적인 형태의 장식 요소를 적용해 주세요.
6. 버튼과 카드에는 부드러운 입체감, 둥근 모서리, 자연스러운 그림자를 적용해 주세요.
7. 모든 콘텐츠 영역에 동일한 디자인 콘셉트를 적용해 주세요.
8. 문의 양식과 Footer 영역까지 전체 홈페이지의 색상과 디자인을 통일해 주세요.
9. 한글 가독성을 높이고 충분한 여백을 확보해 주세요.
10. PC와 스마트폰에서 모두 자연스럽게 보이도록 반응형 디자인을 적용해 주세요.

[중요한 디자인 방향]
첨부 이미지의 따뜻하고 화사한 분위기는 유지하되, 유아적인 느낌이 들지 않도록 해 주세요.
전문성과 신뢰감이 드러나는 세련된 개인 브랜드 홈페이지로 디자인해 주세요.

[기술 조건]
- 기존 텍스트와 콘텐츠를 삭제하거나 변경하지 마세요.
- 기존 메뉴 구조와 링크를 유지해 주세요.
- 기존 슬라이드 기능을 유지해 주세요.
- 기존 문의 양식 및 전송 기능을 유지해 주세요.
- 기존 JavaScript 기능을 유지해 주세요.
- CSS를 중심으로 수정하되, 디자인 구현에 필요한 최소한의 HTML 구조 변경은 허용합니다.
- 실제 3D 이미지가 필요한 경우 필요한 이미지의 종류, 파일명, 권장 크기를 알려 주세요.
- 기존 프로젝트 파일을 분석한 후 직접 수정해 주세요.
- 수정 완료 후 기존 기능이 정상적으로 작동하는지 검증해 주세요.
```

슬라이드 및 문의 양식 유지 조건은 해당 기능이 구현된 경우에 적용한다. 실제 3D 일러스트레이션은 별도의 이미지 파일이 필요할 수 있다.

## STEP 05. 기능 수정 및 검증

### 1. 실습 프롬프트 ⑤ — 기능 수정 및 오류 검증

## STEP 06. GitHub Pages 배포

### 1. Git, GitHub, GitHub Pages의 이해

| 구분         | 설명                                                 |
|--------------|------------------------------------------------------|
| Git          | 소스코드 변경 이력을 관리하는 버전 관리 시스템       |
| GitHub       | 소스코드를 저장하고 공유하는 온라인 플랫폼           |
| GitHub Pages | HTML, CSS, JavaScript 기반 정적 웹사이트 배포 서비스 |

### 2. Git 설치

[Git for Windows 다운로드](https://git-scm.com/downloads/win)에서 설치 파일을 다운로드하여 설치한다. VS Code를 다시 시작하고 **Terminal → New Terminal**을 선택한다.

``` bash
git --version
```

### 3. GitHub 저장소 생성

[GitHub](https://github.com/)에 로그인한 후 **+ → New repository**를 선택한다.

| 설정             | 값                       |
|------------------|--------------------------|
| Repository name  | student-portfolio        |
| Description      | 개인 포트폴리오 홈페이지 |
| Visibility       | Public                   |
| Add README       | 선택하지 않음            |
| Add .gitignore   | None                     |
| Choose a license | None                     |

**Create repository**를 클릭한다. 이 설정은 새 로컬 프로젝트를 비어 있는 원격 저장소에 연결하는 경우를 기준으로 한다.

### 4. VS Code에서 소스코드 업로드

프로젝트 폴더에서 터미널을 열고 다음 명령을 순서대로 실행한다. Git 사용자 정보가 이미 설정되어 있다면 해당 설정은 생략한다.

``` bash
git config --global user.name "GitHub사용자이름"
git config --global user.email "GitHub에등록한이메일"
git init
git branch -M main
git status
git remote -v
```

기존 원격 저장소가 연결되어 있다면 주소를 먼저 확인한다. API Key, `.env`, 비공개 문서 및 백업 파일을 공개 저장소에 올리지 않도록 확인하고 필요하면 `.gitignore`를 설정한다.

``` bash
git add .
git status
git commit -m "개인 포트폴리오 홈페이지 최초 등록"
git remote add origin https://github.com/USERNAME/student-portfolio.git
git push -u origin main
```

`USERNAME`과 저장소 이름을 자신의 정보로 변경한다. `origin`이 이미 존재한다면 `git remote add origin`을 반복 실행하지 않는다. GitHub 인증 화면이 나타나면 인증한다.

강사 실습 저장소: [seunghui-website](https://github.com/victoriouscha/seunghui-website)

### 5. GitHub 업로드 결과 확인

GitHub 저장소에서 `index.html`, CSS, JavaScript, 이미지 파일이 정상적으로 업로드되었는지 확인한다.

> GitHub에서 index.html을 클릭하면 HTML 소스코드가 표시된다. 실제 홈페이지를 보려면 GitHub Pages를 활성화해야 한다.

### 6. GitHub Pages 설정

1.  홈페이지 저장소의 **Settings**를 클릭한다.
2.  왼쪽 메뉴에서 **Pages**를 선택한다.
3.  **Build and deployment**를 다음과 같이 설정한다.

| 설정   | 값                   |
|--------|----------------------|
| Source | Deploy from a branch |
| Branch | main                 |
| Folder | / (root)             |

4.  **Save**를 클릭한다.
5.  배포가 완료되면 Settings → Pages에서 공개 주소를 확인한다.

### 7. 배포된 홈페이지 접속

일반적인 주소 형식:

``` text
https://USERNAME.github.io/student-portfolio/
```

강사 실습 예상 배포 주소: [홈페이지](https://victoriouscha.github.io/seunghui-website/)

홈페이지 콘텐츠, 디자인, 이미지 및 기능이 정상적으로 출력되는지 확인한다. 강사 예제의 최종 배포 성공 여부는 별도로 확인해야 한다.

### 8. 홈페이지 수정 후 다시 배포

Cline으로 홈페이지를 수정한 후 터미널에서 실행한다.

``` bash
git add .
git commit -m "홈페이지 디자인 및 콘텐츠 수정"
git push
```

GitHub Pages가 정상적으로 설정되어 있다면 수정된 홈페이지가 자동으로 다시 배포된다.
